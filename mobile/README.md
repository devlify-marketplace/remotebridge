# mobile/ — iOS & Android Apps (Phase 5+)

- `mobile/controller/` — **Phase 5, built.** The app used to control a
  desktop from a phone (touch input translation, gesture shortcuts,
  on-screen keyboard, biometric lock, session picker). See
  `mobile/controller/README.md` for exactly what's implemented, what's
  deferred, and how to build/run it.
- `mobile/host/` — **Phase 6, built.** The app that lets a phone
  itself be remoted into (screen capture permission flow, mirroring,
  scoped file browser, battery-aware throttling). See
  `mobile/host/README.md` for exactly what's implemented, what's
  deferred (input injection into the phone, iOS background/system-wide
  mirroring, TOTP/whitelist), and how to build/run it.

See `../docs/roadmap.md` (Phase 5 and Phase 6) and
`../docs/features.md` (Mobile-Specific Features section) for scope.
